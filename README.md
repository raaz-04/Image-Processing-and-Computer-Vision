## 📚 About

This repository contains my coursework, assignments, tutorials, experiments, and project work for **EN3160 — Image Processing and Machine Vision** at the **University of Moratuwa, Sri Lanka**.

The course covers fundamental image processing techniques, classical computer vision, machine vision, and deep learning-based vision methods.

---

## 🧠 Course Topics

### 1. Early Vision

- Digital image fundamentals
- Sampling and interpolation
- Point operations
- Linear filtering and convolution
- Edge detection
- Corner detection
- Blob detection
- Cameras, lighting, and color
- Feature extraction
- Optical flow
- Morphological processing
- Frequency-domain processing
- Image compression

### 2. Fitting and Alignment

- Least-squares fitting
- Total least squares
- RANSAC
- Hough transform
- Geometric transformations
- Image alignment
- Image stitching

### 3. Multiple-View Geometry

- Camera models
- Camera calibration
- Epipolar geometry
- Two-view stereo
- Structure from Motion
- Dense 3D reconstruction
- Neural Radiance Fields (NeRFs)
- Gaussian Splatting

### 4. Image Segmentation

- Thresholding
- Region growing
- Active contours
- Level-set methods
- Graph-cut segmentation
- Deep-learning-based segmentation

### 5. Deep Learning for Vision

- Bag of Visual Words
- Linear classifiers
- Convolutional Neural Networks
- Image classification

### 6. Object Detection

- R-CNN
- Fast R-CNN
- Faster R-CNN
- YOLO
- SSD

### 7. Recent Topics

- Vision Transformers
- CLIP
- Segment Anything Model (SAM)
- Vision-Language Models (VLMs)
- Generative models
- Diffusion models
